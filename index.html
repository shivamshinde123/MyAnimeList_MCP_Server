Setup · Python 3.10+, uv

Three steps to your client.

# 1. install
git clone https://github.com/shivamshinde123/MyAnimeList_MCP_Server.git
cd MyAnimeList_MCP_Server
uv sync
cp .env.example .env   # Jikan BASE_URL is preset

# 2. try it in the MCP inspector
npx @modelcontextprotocol/inspector uv run main.py
// 3. add to your MCP client config
{
  "mcpServers": {
    "myanimelist-server": {
      "command": "/path/to/.venv/Scripts/python.exe",
      "args": ["/path/to/main.py"],
      "cwd": "/path/to/MyAnimeList_MCP_Server"
    }
  }
}

On Windows, use absolute paths with double backslashes in the JSON. Pointing at the .venv Python activates the environment automatically.
